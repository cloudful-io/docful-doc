GFM task lists display recorded completion states. These checkboxes are documentation content; update their state in the Markdown source.

## Publication checklist

- [x] Add a descriptive title.
- [x] Include fictional example content.
- [x] Organize the page in a folder.
- [ ] Ask a teammate to review the wording.
- [ ] Publish the next documentation update.

## Nested checklist

- [x] Prepare the example
  - [x] Add a code sample.
  - [x] Add section headings.
- [ ] Review the result
  - [ ] Check narrow-screen layout.
  - [ ] Try keyboard navigation.

## Describe changes

~~Publish without a review.~~ **Review before publishing.** Strikethrough can show superseded wording when that history helps the reader.

## Try it

Compare `- [x]` with `- [ ]` in the source. Use the page copy action to inspect the rendered checklist text.
