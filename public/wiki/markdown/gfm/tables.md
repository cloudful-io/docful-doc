## Feature comparison

| Feature       | Example            | Purpose                          |
| ------------- | ------------------ | -------------------------------- |
| **Bold**      | Interface labels   | Highlight an action              |
| `Inline code` | Filenames          | Preserve exact wording           |
| Task lists    | Review checklist   | Show recorded progress           |
| Headings      | Section navigation | Create table-of-contents entries |

## Column alignment

Colons in the separator row control alignment.

| Left aligned    | Centered  | Right aligned |
| :-------------- | :-------: | ------------: |
| Draft pages     | In review |            12 |
| Published pages |   Ready   |            48 |
| Archived pages  | Complete  |             3 |

These counts are fictional sample data.

## Special characters in cells

| Input        | Meaning                        |
| ------------ | ------------------------------ |
| A \| B       | An escaped pipe inside a cell  |
| **Required** | Inline emphasis works in cells |
| `title`      | A frontmatter field name       |
