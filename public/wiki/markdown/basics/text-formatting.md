## Emphasis

Use **bold text** for interface labels, _italic text_ for emphasis, and _**bold italics**_ when both are useful. GFM also supports ~~outdated instructions~~ so a correction can remain visible.

For example: open **Settings**, select _System_, and replace ~~Auto~~ with **System** in your documentation.

## Inline code and escaping

Wrap filenames such as `src/site.config.ts` and commands such as `npm run dev` in backticks. Use double backticks when the code itself contains a backtick: `` `title` ``.

Escape Markdown punctuation to show it literally: \*not italic\*, \[not a link\], and \# not a heading.

## Paragraphs and line breaks

A blank line starts a new paragraph. A single source newline
usually stays within the same paragraph.

A backslash at the end creates a hard break.\
This sentence starts on the next rendered line.
