Lists make procedures and groups easier to scan. This page shows both numbered steps and nested bullet lists.

## A numbered procedure

1. Create a Markdown file under `public/wiki`.
2. Add frontmatter with a title.
3. Write the page body.
   - Introduce the topic in one paragraph.
   - Add headings for longer sections.
   - Link to related examples.
4. Preview the page locally.

## A nested inventory

- Documentation
  - Getting started
    - Installation
    - First page
  - Reference
    - Configuration
    - Markdown syntax
- Maintenance
  - Review content
  - Remove obsolete instructions

## A list with paragraphs

- **Write for the reader.** Explain what the reader can accomplish.

  A second paragraph remains inside the same list item when it is indented.

- **Keep examples public.** Use fictional names and sample values.

  Never add credentials to the wiki.

## Try it

Copy the list and check that its wording remains useful as plain text. Resize the browser to inspect indentation on a narrow screen.
