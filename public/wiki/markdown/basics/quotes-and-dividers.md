Blockquotes distinguish quoted text from the surrounding explanation. Horizontal rules separate groups of content.

## A short quotation

> Documentation is a product feature: a reader should be able to find an answer and return to their work.
>
> This is fictional sample copy, included to demonstrate a multi-paragraph quotation.

## Nested quotations

> Reviewer: Can a page explain one task clearly?
>
> > Author: Yes. Start with the outcome, then provide the steps.
