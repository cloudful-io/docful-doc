Use this page as a tour of the documentation reader. It contains the distinctive phrase **copper lantern walkthrough** for a body-text search experiment.

## Search experiments

1. Search for `Tables and alignment` to find a title match.
2. Search for `Column alignment` to find a heading match on the tables page.
3. Search for `copper lantern walkthrough` to find this page through body text.

Title matches rank above heading matches, followed by body-only matches. Within each group, newer file modification timestamps appear first.

### Keyboard shortcut

From elsewhere on a page, press Command-K on macOS or Ctrl-K on Windows/Linux to focus search. The small key hint in the textbox helps readers discover the shortcut.
