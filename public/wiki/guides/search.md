---
title: Search and navigation
---

Search covers page titles, section headings, and all rendered Markdown text across nested folders.

## Search ranking

Results with matching titles appear first, followed by heading matches and then body matches. Within each group, recently modified pages appear first.

## Organize pages

Use folders under `public/wiki` to create nested navigation. At each level, folders appear before pages, and both groups are sorted alphabetically.

### Copy text

The page copy action copies rendered text so it can be pasted into another application.
