# Agent Instructions

Before modifying the repository:

1. Read `docs/development.md`.
2. Read the assigned GitHub Issue completely.
3. Read `docs/system-architecture.md` and other relevant documentation under `docs/`.
4. Determine the acceptance criteria.
5. Do not expand scope beyond the Issue.

Before creating a PR:

1. Run lint.
2. Run typecheck.
3. Run tests.
4. Verify the Issue acceptance criteria.
5. Report any deviations explicitly.
