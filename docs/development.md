# Agent Development Rules

1. Read `docs/product-requirements.md` before beginning work.
2. Read `docs/system-architecture.md` before modifying architecture.
3. Read `docs/package-api.md` before changing public APIs.
4. Work only on the assigned GitHub Issue.
5. Do not expand scope without creating/updating an Issue.
6. Add or update tests with implementation changes.
7. Run lint, typecheck, and tests before creating a PR. Use the commands documented by the project.
8. Do not modify unrelated files.
9. Do not close Issues directly; the PR closes them.
10. Update documentation when changing public behavior.
